# Política de Seguridad

## Versiones Soportadas

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | ✅ Yes             |
| < 2.0   | ❌ No              |

## Reportando Vulnerabilidades

Por favor, NO abras un issue público para reportar vulnerabilidades de seguridad.

En su lugar, envía un email a: produccion@almadelascosas.com

Por favor incluye:
- Descripción detallada de la vulnerabilidad
- Pasos para reproducir
- Impacto potencial

Te responderemos dentro de 48 horas.

## Medidas de Seguridad

- Este proyecto se basa en librerías mantenidas activamente
- Actualizamos dependencias regularmente
- Usamos type hints para mayor seguridad
- Se realizan validaciones de entrada
- Existe manejo robusto de excepciones

## Actualizaciones de Seguridad

Para recibir notificaciones de actualizaciones de seguridad, activa las alertas
de dependencias en GitHub.
