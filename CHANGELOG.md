# Changelog

Todos los cambios notables en este proyecto se documentan en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/) y este
proyecto se adhiere a [Semantic Versioning](https://semver.org/).

## [2.0.0] - 2024-07-27

### Added
- ✨ Arquitectura modular profesional con separación de responsabilidades
- 📚 Documentación completa con docstrings y type hints
- 🧪 Suite de pruebas unitarias con pytest
- 📝 Sistema de logging comprensivo
- ✅ Validaciones profesionales de entrada
- 🎨 Interfaz mejorada con mejor UX en Streamlit
- 🔧 Herramientas de calidad de código (black, ruff, flake8, isort)
- 📋 Archivos de configuración GitHub profesionales
- 🚀 Pre-commit hooks para garantizar calidad
- 📊 Manejo robusto de errores y excepciones

### Changed
- 🔄 Refactorización completa del código base
- 📦 Nueva estructura de carpetas (services/, utils/, tests/)
- 🎯 Separación de lógica en módulos independientes
- 💾 Optimización del caching de datos

### Fixed
- 🐛 Manejo mejorado de casos edge
- 🛡️ Mayor robustez ante datos incorrectos

## [1.0.0] - 2024-01-01

### Initial Release
- Calculadora básica de precios de marcación
- Interfaz Streamlit funcional
- Carga de datos desde Excel
